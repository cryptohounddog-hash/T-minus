# T-Minus Dashboard

Mission Control for the life you're building.

A customizable, full-screen life dashboard: countdowns, goals, habits, calendar, journal, and progress — arranged as widgets you can move, resize, and hide. Ships with two starter templates (Adult Mission Control and Student Starpath) and lets you fully re-skin the text, colors, and profile without touching code.

Everything is saved locally in the browser (`localStorage`) — this is a prototype/builder foundation, not yet a hosted multi-user product (see Settings → Data for more on that).

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
